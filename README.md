# MRI Slice Interpolation — Deep Learning Project

U-Net that learns to reconstruct missing MRI slices from two neighboring acquired slices,
simulating ×2 accelerated acquisition on the IXI brain dataset.

---

## Project structure

```
Project/
├── documentation/              # conceptual docs — DO NOT MODIFY
├── src/
│   ├── config.py               # all paths & hyperparameters
│   ├── preprocess.py           # NIfTI loading, 2.5D pair creation, baselines
│   ├── train.py                # U-Net model, training loop, evaluation
│   └── explainability.py       # Grad-CAM & Integrated Gradients
├── data/
│   ├── raw/                    # place .nii / .nii.gz files here
│   └── processed/              # generated by preprocess.py
├── models/                     # saved checkpoints (unet_best.pth)
├── outputs/
│   ├── figures/                # training curves, predictions, distributions
│   ├── metrics/                # baseline & test metric arrays (.npy)
│   └── explainability/         # Grad-CAM and IG visualisations
├── logs/                       # SLURM stdout/stderr
├── requirements.txt
├── job_run_gpu.sh              # UBELIX HPC SLURM script
└── README.md
```

pip install -r requirements.txt

## Running locally

Each script is a standalone module. Run from the **project root** so that
`from src.xxx import ...` resolves correctly.

```bash
# 1. Preprocess raw scans → data/processed/
python -m src.preprocess

# 2. Train U-Net → models/unet_best.pth + outputs/
python -m src.train

# 3. Explainability analysis → outputs/explainability/
python -m src.explainability
```

---

## Running on UBELIX HPC

Place raw `.nii` / `.nii.gz` files in `data/raw/`, then submit:

```bash
sbatch job_run_gpu.sh
```

Logs are written to `logs/<jobname>_<jobid>.out` / `.err`.

## Configuration

All hyperparameters and paths are centralised in [src/config.py](src/config.py).
Edit that file to change:

| Parameter            | Default          | Description                          |
|----------------------|------------------|--------------------------------------|
| `ACCELERATION_FACTOR`| `2`              | Simulated MRI undersampling ratio    |
| `TARGET_SIZE`        | `(256, 256)`     | Axial slice resize target            |
| `BATCH_SIZE`         | `8`              | Training batch size                  |
| `NUM_EPOCHS`         | `20`             | Number of training epochs            |
| `LEARNING_RATE`      | `1e-3`           | Adam initial learning rate           |
| `LOSS_ALPHA`         | `0.8`            | L1 weight in combined L1 + SSIM loss |
| `UNET_FEATURES`      | `[32,64,128,256]`| Encoder channel progression          |
| `N_EXPL_SAMPLES`     | `6`              | Samples analysed by explainability   |
| `IG_STEPS`           | `50`             | Integration steps for IG             |

## Results (IXI dataset, 581 scans, ×2 acceleration)

| Method          | PSNR (dB)      | SSIM           | MAE     |
|-----------------|----------------|----------------|---------|
| Linear interp.  | 33.21          | 0.9066         | —       |
| Cubic spline    | 33.19          | 0.9048         | —       |
| **U-Net (ours)**| **35.95 ± 6.54**| **0.9455 ± 0.0294** | 0.00939 |

Improvement over linear baseline: **+2.74 dB PSNR**, **+0.0389 SSIM**.

---

## Model

7.76M-parameter U-Net with four encoder levels (32 → 64 → 128 → 256 channels),
a 512-channel bottleneck, and symmetric decoder with skip connections.
Loss: `0.8 × L1 + 0.2 × (1 − SSIM)`.

---

## Explainability

- **Grad-CAM** hooks into the last decoder block to visualise spatial attention.
- **Integrated Gradients** attributes each input pixel for both the left and right
  neighboring slices (left/right ratio ≈ 0.95 — near-symmetric, as expected).
